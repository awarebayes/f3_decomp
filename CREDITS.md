# Credits

Fallout 3 was rebuilt function by function by a community of contributors, coordinated on
[f3decomp.com](https://f3decomp.com). These contributors chose to be named; the numbers are the functions and bytes of verified
matches each of them handed in (as of 2026-11-20). A function reopened for rework and matched again counts for both
the first matcher and the reworker. 18 further contributors took part anonymously.

| Contributor | Functions | Bytes |
|---|---:|---:|
| [mathisto](https://github.com/mathisto) | 712 | 889846 |

The rest of the code was matched by the project's own tooling.
